# Changelog

## 0.1.0 — 2026-11-26

First standalone open-source beta. Introduces persisted construction project control, traceable metrics, approval workflows, schedule revision history, material and crew registers, scoped report publication, PDF/Excel exports, project templates, access controls and local/hosted deployment instructions. Bidlark integration remains a separate future phase.

## 0.2.0 — 2026-11-26

Complete standalone feature pass: production/financial/schedule analysis, person calendars, expanded approvals, collaboration and notifications, nine branded report layouts, multiple organizations, optional OIDC, encrypted backup/recovery and retention/telemetry, scheduled report delivery, verified workspace signup and optional Stripe hosted entitlements. Adds native PostgreSQL, identity, import-dependency, security and scanner acceptance coverage. Bidlark remains disconnected.
